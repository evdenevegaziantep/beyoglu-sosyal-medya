# Medya klasörü

Yayınlanacak video/fotoğraflar buraya konur (`medya/` altında).
Dosya adları `schedule.json` içindeki yollarla aynı olmalı.

Örnek: `medya/gun02-01.png` → schedule.json'da `"medya/gun02-01.png"`

Bu klasöre dosyaları yapay zekâ asistanın otomatik yükler (kurulumda verilen
GitHub erişim anahtarı ile). Senin yapman gereken bir şey yok.
